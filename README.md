# 📊 Marketing Analytics & Customer Sentiment Analysis Dashboard

### End-to-End Marketing Analytics Project using SQL Server, Python, NLP Sentiment Analysis, and Power BI

---

## 📌 Project Overview

This project focuses on transforming raw marketing and customer interaction data into meaningful business insights through:

- SQL-based data cleaning and transformation
- NLP sentiment analysis using VADER
- Data modeling in Power BI
- Interactive dashboard development
- KPI tracking and business reporting

The solution integrates customer reviews, engagement metrics, and customer journey data to provide a comprehensive analytics dashboard for business decision-making.

---

# 🚀 Key Features

- SQL-based data cleaning and transformation
- Customer sentiment analysis using NLP
- Customer journey and conversion analysis
- Marketing campaign performance tracking
- Interactive Power BI dashboard
- KPI monitoring and trend analysis
- Data modeling using Star/Galaxy schema concepts
- DAX-based business calculations
